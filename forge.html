Inspector

Wire a plate or lever to this sign with the Link tool to pop it on cue.

Story Slides

Static-image cutscenes with fade transitions. Intro plays before the level starts; Outro plays after escaping. Each slide is an optional image plus a caption (max 12 per reel). Slides are saved in the level JSON. Playtest skips cutscenes; the game plays them.

Custom Library

Define your own placeable objects. Upload art, name it, and choose how it behaves. Each object becomes a stamp tool — click it, then click the map to place. Collision: None (decoration), Blocks sight (a pillar you walk past but guards cannot see through), or Solid wall (blocks movement and sight, snaps to the grid). Everything is saved in the level JSON.

Enemy Types

Design invader types: tune speed, sight, perception, inventory size (Plunder), and pick special abilities. Each type becomes a stamp tool — place it like any invader, then add patrol waypoints. Falls back to the base look (Fighter/Rogue/Wizard).

Custom Art

Per-object art: select any placed object with the Select tool and use the “🎨 Object art” button (bottom-left) to give that single instance its own image — two barrels can look completely different, and copying a disguise copies its art. Slot uploads below remain the per-kind defaults. Slots: Upload a PNG for any slot. Animation: a strip of 2–16 square frames laid out horizontally auto-loops at 8 fps (great for water tiles, banners, torches). Characters animate procedurally — facing flip plus squash-and-stretch — so a single sprite is all they need. Every floor and wall type can have its own texture, plus an optional looping music track. Everything is saved inside the level JSON, so exported levels carry their look and sound with them. Floor textures are auto-mirrored on alternating tiles to reduce repetition. Clear any slot to return to built-in art.
